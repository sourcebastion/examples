Methodology

  • Rubric: project-security-v2. Grades are computed by stock SourceBastion; nothing was adjusted by hand, and no finding was manually reviewed.
  • Scanner: ghcr.io/sourcebastion/sourcebastion-scanner, run on a shallow clone of each default branch and uploaded through SourceBastion's customer-CI API (no webhooks, no access to the projects' repositories).
  • Most grades are Provisional: License exposure is not assessed without an intended-use policy. Remediation is graded by the stock rubric from the project's SourceBastion history.
  • Stock product limits apply. A project a limit stops is shown as "Not assessed" with the product's reason.
  • A project this run could not clone, scan or upload is shown as "Failed", naming the scanner that stopped when the scan recorded one. These are mostly very large repositories. Most were retried with a 30-minute limit for each scanner, and some also with one scanner at a time.
  • Counts are unique actionable findings per category. No finding detail is published.
